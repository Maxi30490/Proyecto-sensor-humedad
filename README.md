# Proyecto-sensor-humedad
Arduino - taller ingeniería - grupo 3
El proyecto aborda el desperdicio de agua y el deterioro de plantas domésticas causados por el riego ineficiente (tanto por exceso como por déficit hídrico), alineándose con el ODS 6. Funciona mediante un sensor capacitivo que mide la humedad del suelo y envía una señal analógica a un microcontrolador Arduino Uno, el cual procesa el dato a porcentaje (0% a 100%) en menos de un segundo y lo despliega en una pantalla TFT mediante colores y categorías intuitivas (seco, óptimo o húmedo).
Componentes Utilizados: Microcontrolador (1 placa Arduino Uno (mega2560), sensor: 1 sensor capacitivo de humedad de suelo v1.2, e interfaz visual: 1 pantalla TFT LCD ILI9341 de 2.8 pulgadas.
